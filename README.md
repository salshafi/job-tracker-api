# Job Application Tracker API

A REST API for tracking job applications, built with FastAPI, SQLAlchemy and SQLite. You can save a posting, move it through the hiring stages, and filter your list by status.

## Features

- Create, list, view, update and delete job applications
- Five allowed statuses: `saved`, `applied`, `interview`, `offer`, `rejected`
- Input validation with Pydantic (empty company/role and unknown statuses return `422`)
- Partial updates with `PATCH`: only the fields you send are changed
- Filter the list by status, e.g. `GET /applications?status=applied`
- Health check at `GET /health`
- Automated tests with pytest, using a throwaway in-memory database
- Interactive API docs generated by FastAPI at `/docs`

## Tech Stack

Python · FastAPI · SQLAlchemy 2 · SQLite · Pydantic · Uvicorn · pytest

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| POST | `/applications` | Create an application (`201`) |
| GET | `/applications` | List applications, newest first. Optional `?status=` filter |
| GET | `/applications/{id}` | Get one application (`404` if missing) |
| PATCH | `/applications/{id}` | Update only the fields sent |
| DELETE | `/applications/{id}` | Delete an application (`204`) |
| GET | `/health` | Service check |

### Application fields

| Field | Type | Notes |
|-------|------|-------|
| `company` | string | Required, 1–100 characters |
| `role` | string | Required, 1–100 characters |
| `status` | string | One of the five statuses. Defaults to `saved` |
| `job_url` | string | Optional |
| `date_applied` | date | Optional, `YYYY-MM-DD` |
| `notes` | string | Optional |
| `id`, `created_at` | | Set by the server |

## Run It

Requires Python 3.11+ (uses `StrEnum` and `X | None` type syntax).

```bash
git clone https://github.com/salshafi/job-tracker-api.git
cd job-tracker-api
python -m venv venv
source venv/Scripts/activate      # Windows Git Bash. On Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000/docs to try every endpoint in the browser. The SQLite file `job_tracker.db` is created automatically on first run.

## Run the Tests

```bash
pytest
```

The tests cover create, defaults, validation errors, listing and filtering, partial updates, `404` handling and delete.

## Notes

- Built to practise designing a REST API end to end: data model, validation, routes and tests.
- There is no user login. This is a single-user tool and the database is a local SQLite file.
- Possible next steps: JWT authentication, a React front end, and a Postgres database.
